## Unreleased changes
- Added a Scale setting to HUDs that stays in sync with the HUD editor's corner handles
- Added HUD groups: group HUDs from the editor's context menu or hover bar to drag and scale them as one box, use the group's own settings for a shared scale and lock, double-click a group to edit inside it, and nest groups inside other groups. Mods can group their HUDs by default with `HudGroups.registerDefault`
- Dropped compatibility with Hypixel SkyBlock mods (Apec, Firmament, Odin, Skyblocker, SkyHanni and other MoulConfig-based mods) on Minecraft versions below 26.1, which can no longer be used to play SkyBlock
